# Baxter ROS Noetic – Project overview

Group project on **Bayesian Optimization with transfer learning** for sequential object placement and rearrangement with collision-free arrangements on cluttered surfaces. The system targets efficient planning for robotic manipulation tasks in complex environments.

**My role:** Physical robot side. I updated the Baxter codebase to run on **ROS Noetic** (Python 3, compatible tooling and simulation in Gazebo).

**Tech stack:** ROS Noetic, Catkin, Baxter SDK (interface, tools, examples, MoveIt, Gazebo).

See [README.md](README.md) for the current Noetic quick start, Docker workflow, simulator basics, MoveIt basics, tests, and troubleshooting.
